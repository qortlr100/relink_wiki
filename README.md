# Relink Wiki

개인적으로 구축하고 운영하는 **Granblue Fantasy: Relink 데이터베이스 위키** 프로젝트입니다.

## 프로젝트 방향

- 공개 영역은 누구나 탐색할 수 있는 위키 형태로 구성합니다.
- 시각 디자인은 짙은 남색과 금색을 사용하는 Sky-Island Archive 방향을 기반으로 합니다.
- 데이터 추출, 원본 경로, 작업 로그와 검수 기능은 공개 사이트에서 분리합니다.
- 마이닝 관리는 로컬에서만 실행되는 웹 대시보드로 구성합니다.
- 게임 원본 데이터와 로컬 데이터베이스는 Git에 저장하지 않습니다.
- GitHub를 코드와 문서의 기준 저장소로 사용하고, 공개 위키는 Sites로 배포합니다.

## 예정 구조

```text
apps/
├── wiki/              # 공개 위키
└── mining-admin/      # localhost 전용 관리 화면

tools/
└── extractor/         # 추출·변환·검증 스크립트

data/
├── raw/               # 게임 원본 추출물 (Git 제외)
├── local/             # 로컬 SQLite DB (Git 제외)
└── exports/           # 배포용 산출물 (Git 제외)

docs/                  # 구조·마이닝·운영 문서
```

## 데이터 운영 원칙

로컬 SQLite를 기준 데이터베이스로 사용하고, 검수된 공개 데이터만 배포용 저장소로 발행합니다.

```text
게임 파일 → 로컬 추출 → SQLite 정규화 → 변경점 검수 → 공개 데이터 발행 → 위키
```

## 로컬 시작

프로젝트 소스가 추가된 뒤 구체적인 설치 및 실행 명령을 이 문서에 기록합니다.
